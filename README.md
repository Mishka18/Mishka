# 🏋️ Training Planner - Планировщик тренировок

**Автор:** Кучеренко Михаил
**Дата:** апрель 2026

## 📝 Описание

**Training Planner** — это десктопное приложение для планирования и учета тренировок. 
Программа позволяет добавлять, фильтровать, сохранять тренировки, а также 
интегрирована с системой контроля версий Git.

### Основные возможности

- ✅ Добавление тренировок с валидацией данных
- 🔍 Фильтрация по типу тренировки и дате
- 💾 Сохранение и загрузка данных в JSON формате
- 📊 Статистика тренировок
- 🐙 Интеграция с Git (автоматические коммиты)
- 🗑️ Удаление и редактирование записей
- 📈 Сортировка по дате
- 💾 Автоматическое создание резервных копий
